Frequently Asked Questions

Will the indigo bleed onto my couch or other pillows when it's new?

Most ikat woven covers are pre-washed to minimize bleeding, but new deep indigo fabrics can release a tiny amount of dye in the first wash. Wash it separately in cold water before placing it on light-colored furniture. After that first wash, bleeding essentially stops. If you're paranoid about this, test it on a white cloth first—it's a five-minute precaution that prevents any regrets.

How does this compare to printed ikat pillow covers that cost less?

Huge difference. Woven ikat means the pattern goes through the entire fabric, so it doesn't wear off or fade from the front like printed versions do. Printed covers look good for maybe six months if you use them regularly; woven covers maintain clarity for years. You're paying extra because the construction is fundamentally different and longer-lasting. If you're washing these monthly, the woven version justifies the cost difference.

Does the 18x18 size work with standard throw pillow inserts?

Yes, it fits standard 18x18 down or polyester inserts perfectly. If you want a fuller, plumper look, go up to an 20x20 insert and it'll still work, though it'll be slightly snug. The cover has a bit of give, so don't panic about sizing—most people use standard sizing and it looks balanced. If you're pairing this with other pillows, stick with matching insert sizes so everything looks cohesive.

Is indigo hard to match with other decor, or is it versatile?

Indigo is surprisingly versatile. It works with neutrals (gray, white, cream, black), warm woods, other blues, and even rust or terracotta accents if you're going bohemian. The challenge isn't matching it—it's avoiding too many competing patterns in one space. Pair it with solid-colored pillows or very subtle patterns so the ikat weave stays the visual anchor. If your couch is already bold-patterned, this might be too much visual stimulation.
